rdpkey

Проброс горячих клавиш в полноэкранный RDP RemoteApp.

Зачем. В обычном RemoteApp клавиши Win, Alt+Tab, Ctrl+Esc срабатывают на вашем компьютере, а не в удалёнке. rdpkey перехватывает их и отправляет в удалённый сеанс — пока он развёрнут на весь экран.

Запуск

  1. Нажмите большую кнопку «Запустить удалёнку с пробросом клавиш». При первом запуске программа попросит указать файл удалёнки от работодателя (.rdp в режиме RemoteApp). Если выбрать не тот файл, программа предупредит об этом.
  2. Откроется удалёнка (mstsc). Разверните её на весь экран — проброс работает только в полном экране.
  3. Горячие клавиши теперь уходят в удалёнку. Галочками включайте/выключайте отдельные сочетания.
Файл запоминается. После первого запуска программа показывает строку «Подключение к: …» с именем файла и — если это указано в подписи файла — датой, до которой файл действует. Кнопка «изменить» рядом позволяет выбрать другой файл. В следующий раз большая кнопка запускает удалёнку сразу, без повторного выбора.
Срок действия файла. Если до окончания срока действия файла удалёнки остаётся меньше 30 дней, строка «Подключение к: …» становится красной. Наведите на неё курсор — появится подсказка. По истечении срока подключение перестанет работать: запросите новый файл в службе поддержки.
Срок действия персонального сертификата. При подключении программа проверяет ещё и ваш персональный сертификат для удалённого доступа в хранилище Windows. Если до его окончания осталось меньше 30 дней или он уже истёк, появится сообщение об ошибке (его нельзя закрыть сразу). В этом случае зарегистрируйте заявку на продление в Service Desk. Проверка срабатывает при любом запуске удалёнки — в том числе по двойному клику на .rdp.

Какие клавиши пробрасываются

WinОткрыть «Пуск» в удалёнке
Win+R«Выполнить»
Win+EПроводник
Win+DПоказать рабочий стол
Win+TabПредставление задач
Win+VЖурнал буфера обмена
Win+ZСвернуть удалёнку (локально прячет полноэкранное окно)
Alt+TabПереключение окон вперёд
Alt+Shift+TabПереключение окон назад
Ctrl+EscОткрыть «Пуск»

Ctrl+Shift+Esc и Ctrl+Alt+Tab намеренно остаются локальными.

Не хотите запускать программу каждый раз?

rdpkey автоматически прописывает себя в список «Открыть с помощью» для файлов .rdp (не заменяя приложение по умолчанию). Если вам удобнее открывать удалёнку двойным кликом сразу через rdpkey, назначьте его приложением по умолчанию вручную один раз:

  1. Правый клик по вашему файлу .rdp → «Свойства».
  2. В строке «Приложение» нажмите «Изменить…».
  3. Выберите «RDP RemoteApp Hotkeys (rdpkey)» и нажмите «ОК».

То же можно сделать через правый клик по .rdp → «Открыть с помощью» → «Выбрать другое приложение» → rdpkey → «Всегда».

Если что-то не работает

  • «Это не файл удалёнки в режиме RemoteApp». Выбран обычный .rdp (полный рабочий стол). Нужен файл RemoteApp, выданный работодателем.
  • Горячие клавиши не проходят. Убедитесь, что удалёнка развёрнута на весь экран — в оконном режиме все комбинации остаются на вашем компьютере.
  • Строка подключения красная. Срок действия файла удалёнки подходит к концу — запросите новый файл в службе поддержки.
  • В списке «Открыть с помощью» несколько похожих приложений. Наше называется «RDP RemoteApp Hotkeys» и указывает на rdpkey.exe. Другие (например «rdphotkey» или старые версии) можно убрать вручную.

rdpkey — локальная утилита: не отправляет ничего в сеть, не ведёт логов, обычный набор текста не перехватывает (только сочетания с Win и Alt).
