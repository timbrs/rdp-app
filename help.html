rdpkey

Проброс горячих клавиш в полноэкранный RDP RemoteApp.

Зачем. В обычном RemoteApp клавиши Win, Alt+Tab, Ctrl+Esc срабатывают на вашем компьютере, а не в удалёнке. rdpkey перехватывает их и отправляет в удалённый сеанс — пока он развёрнут на весь экран.

Запуск

  1. Нажмите большую кнопку «Запустить удалёнку с пробросом клавиш» и выберите свой .rdp.
  2. Откроется удалёнка (mstsc). Разверните её на весь экран — проброс работает только в полном экране.
  3. Горячие клавиши теперь уходят в удалёнку. Галочками включайте/выключайте отдельные сочетания.

Какие клавиши пробрасываются

WinОткрыть «Пуск» в удалёнке
Win+R / E / DВыполнить / Проводник / Рабочий стол
Win+Tab / VПредставление задач / Журнал буфера обмена
Win+ZСвернуть удалёнку (локально прячет полноэкранное окно)
Alt+Tab / Alt+Shift+TabПереключение окон вперёд / назад
Ctrl+EscОткрыть «Пуск»

Ctrl+Shift+Esc и Ctrl+Alt+Tab намеренно остаются локальными.

Открывать .rdp сразу через rdpkey

Галочка «Всегда открывать удалёнку с пробросом» (в синей рамке) регистрирует rdpkey как приложение для файлов .rdp — после этого он появляется в списке «Открыть с помощью». Снять галочку — убрать регистрацию (файлы вернутся к обычному mstsc).

Важно про «по умолчанию». Windows 10/11 не разрешает программе назначать себя приложением по умолчанию (это защита от «угона» ассоциаций). Поэтому галочка только регистрирует rdpkey. Чтобы .rdp открывались по двойному клику именно через rdpkey, назначьте его по умолчанию один раз вручную — любым из способов:
  • Правый клик по любому .rdp → «Открыть с помощью» → «Выбрать другое приложение» → выберите RDP RemoteApp Hotkeys (rdpkey) → отметьте «Всегда».
  • Или кнопка «Открыть „Приложения по умолчанию“ Windows» в окне rdpkey → в поиске введите .rdp → выберите текущее приложение → укажите rdpkey.

Если что-то не работает

  • Не удалось зарегистрировать (.rdp). Закройте другие окна rdpkey и нажмите галочку снова; запускайте rdpkey с локального диска (не из архива или сетевой папки); проверьте доступ к папке %LOCALAPPDATA%\rdpkey.
  • Горячие клавиши не проходят. Убедитесь, что удалёнка развёрнута на весь экран — в оконном режиме все комбинации остаются на вашем компьютере.
  • В списке «Открыть с помощью» несколько похожих приложений. Наше называется «RDP RemoteApp Hotkeys» и указывает на rdpkey.exe. Другие (например «rdphotkey» или старые версии) можно убрать вручную.
  • Выбранное «по умолчанию» не сохраняется. Это ограничение Windows 11 — назначайте через правый клик → «Открыть с помощью» → «Выбрать другое приложение» → «Всегда», либо через «Параметры → Приложения по умолчанию».

rdpkey — локальная утилита: не отправляет ничего в сеть, не ведёт логов, обычный набор текста не перехватывает (только сочетания с Win и Alt).
